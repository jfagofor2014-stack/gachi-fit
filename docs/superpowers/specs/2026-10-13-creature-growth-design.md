# キャラクター育成（ジムモン） 設計書

## ゴール

「週に2回、それぞれ30分以上トレーニングする」習慣を、育成ゲームにして続けやすくする。続けて重量や回数が伸びるとキャラが進化し、サボると弱くなる。

## 前提・調査結果

- 今回の要望: 週2回×30分以上の継続と、重量が増えることで育つ。おろそかにすると弱くなる
- 回答済みの決定: キャラは**育成モンスター**（6段階の進化、サボると色が褪せて元の姿に戻る）。弱体化は**標準**（1回で少し、0回で大きく）。**週単位のお休み**が必要。成長ペースは**速め（毎週達成で約1か月半でレジェンド）**
- 「30分」を測る所要時間は、現状では記録タブの「場所・時間」に開始・終了を手入力したときの `workout.durationSec` にしか残らない。音声中心の記録に手入力は合わないため、**セット保存時刻（`sets.createdAt`）から自動で推定**する
- 自宅の土台でダンベルが最大30kgに頭打ちになるため、成長の条件を「重量が増えた」だけにすると止まる。**推定1RMの更新、または同じ重量以上での最大回数の更新**を自己ベストとして扱う
- 週は月曜始まり。日付は `workout.date`（ローカル日付 `YYYY-MM-DD`）で扱い、UTC変換はしない
- 既存データ: `workouts`（`{id, date, startTime, endTime, durationSec, ...}`、1日1件）、`sets`（`{workoutId, exerciseId, weight, reps, assistedReps, estimated1RM, createdAt}`）、`exercises`（`bodyweight` を持つ）、`goals`（`id` で識別する汎用ストア。現在は `'main'` のみ）
- ホーム最上部にはまだカードがない。体重の登録は 分析 > ボディ にある
- ジム時代の記録は所要時間が残っていないため、育成の計算には**開始週より前を使わない**（ただし「自己ベスト更新」の比較対象には、開始週より前の全履歴を使う）

## 中核の設計判断

### 判断1: 状態を保存せず、履歴から毎回計算する

強さ・段階・気分は、`workouts` / `sets` / 開始週 / お休み週から**純粋関数で再計算**する。増減を保存しないので、記録の削除・修正・お休みの切替が自動で整合し、テストも書きやすい。保存するのは次の3つだけ。

### 判断2: 保存は既存の `goals` ストアに1件

`goals` に `{ id: 'creature', startWeek: 'YYYY-MM-DD', restWeeks: ['YYYY-MM-DD', ...], lastSeenStage: number }` を置く。ストア構成と `DB_VERSION` は変えない。ホームを初めて開いたとき、存在しなければ `startWeek` を今週の月曜にして作る。

### 判断3: 弱体化は段階を戻すが、記録は消さない

強さが下がると段階が戻り、姿がしょんぼりになる。履歴・PR・記録そのものには影響しない。強さの計算は「週が終わってから」確定するので、今週の途中では増減しない。

## ルール

### 定数（`js/lib/creature.js` に集約し、調整はここだけで行う）

| 定数 | 値 | 意味 |
|---|---|---|
| `WEEKLY_GOAL` | 2 | 週の目標回数 |
| `SESSION_MIN` | 30 | 達成とみなす所要時間（分） |
| `LEAD_IN_MIN` | 5 | 自動推定に足す分（最初の種目をやっている間は記録が出ないため） |
| `START_POWER` | 10 | 開始時の強さ（ベビー） |
| `GAIN_FULL` | 10 | 目標回数を達成した週の増加 |
| `LOSS_ONE` | 5 | 1回だけの週の減少 |
| `LOSS_ZERO` | 15 | 0回の週の減少 |
| `BONUS_PER_EVENT` | 2 | 自己ベスト更新1種目あたりの加点 |
| `MAX_EVENTS` | 3 | 1週に加点する自己ベスト更新種目の上限 |
| `BW_TOLERANCE` | 3 | 自重種目で「同じ重量以上」を判定するときの許容（kg） |

強さは 0〜100 に丸める。

### 1日の所要時間（`sessionMinutes`）

その日（`workout.date` が同じ）にセットが1件以上ある日を「トレーニングした日」とする。所要時間は次のとおり。

1. その日の `workout` のどれかに `durationSec > 0`（手入力の開始・終了）があれば、その最大値を分に直して使う
2. なければ、その日の `sets.createdAt` の最大と最小の差（分）に `LEAD_IN_MIN` を足す。セットが1件、または1回の保存だけなら差は0なので `LEAD_IN_MIN`（5分）になる

`所要時間 >= SESSION_MIN` の日を「達成した日」とする。

### 自己ベスト更新（`progressExerciseIds`）

ある週に、種目 X が次のいずれかを満たすとき、X を「その週に更新した種目」とする。比較対象は、**その週より前**の X の全セット（以下 prior）。prior が空なら（初めて記録した種目）対象外。

- (a) その週の X の最大推定1RM が prior の最大より大きい。推定1RMは `computePRs` と同じく、補助回数を引いた回数で計算する
- (b) その週の X のセット s のうち、`netReps(s) > max{ netReps(p) : p ∈ prior かつ p.weight >= s.weight − tol }` となるものがある。`netReps = reps − assistedReps`、`tol` は自重種目なら `BW_TOLERANCE`、それ以外は 0。条件に合う p が1件もなければ (b) は成り立たない

### 週の増減（`closed` な週のみ）

達成した日の数を q、加点対象の更新種目数を e（上限 `MAX_EVENTS`）とする。ただし**加点は q ≥ 1 の週だけ**。

| 条件 | 増減 |
|---|---|
| お休み週 | 0（加点もなし） |
| q ≥ `WEEKLY_GOAL` | `+GAIN_FULL + e × BONUS_PER_EVENT` |
| q = 1 | `−LOSS_ONE + e × BONUS_PER_EVENT` |
| q = 0 | `−LOSS_ZERO` |

達成した日が3回以上でも増加は変わらない（加点は更新種目による）。

### 段階（`stageFor(power)`）

| 強さ | 0–9 | 10–29 | 30–49 | 50–69 | 70–89 | 90–100 |
|---|---|---|---|---|---|---|
| 段階 | 0 たまご | 1 ベビー | 2 こども | 3 ヤング | 4 マッスル | 5 レジェンド |

毎週満点（`+10` に加点`+4`程度）なら、約2週で「こども」、約6〜7週で「レジェンド」に届く。

### 気分（`moodFor`）

1. 今週の達成した日が `WEEKLY_GOAL` 以上 → `genki`
2. そうでなければ、直近の**終了した非お休み週**の結果で決める: q ≥ 2 → `genki` / q = 1 → `normal` / q = 0 → `shobori`
3. 終了した非お休み週がまだない → `normal`

## 画面

### ホームの最上部のカード（`js/views/creature.js`）

```
┌───────────────────────────────┐
│ [キャラ]   ヤング               │
│            強さ ████████░░ 62   │
│            次の進化まで あと8    │
│ 今週  ● ○   あと1回で達成（残り3日）│
│ ▸ くわしく                      │
└───────────────────────────────┘
```

- キャラは `monsterSvg(stage, mood)`（`js/lib/creatureArt.js`）で描く SVG
- 強さバーは 0〜100。次の進化までの残りを表示する。レジェンドでは「最高の姿」と出す
- 今週の達成状況は ●（達成）と ○（未達）を `WEEKLY_GOAL` 個並べ、文言は次のとおり
  - 達成: 「今週の目標達成！」
  - 未達: 「あと{n}回で今週達成（残り{d}日）」。`d` は今日を含む今週の残り日数
  - お休み週: 「今週はお休み」
- 「くわしく」を開くと `<details>` で次を出す
  - 直近8週（または開始週以降）の一覧。各行は「10/5〜10/11」「結果アイコン（✔ 2回以上／△ 1回／✕ 0回／休 お休み／進行中）」「強さの増減」
  - その週の達成した日と未達の日の所要時間（例: 「10/6 38分 ✔　10/9 24分」）。**30分の判定が見えるようにする**
  - 各週の「お休みにする／戻す」ボタン（今週と、開始週以降の過去週）
  - ルールの要約（週2回×30分、強さの増減、自己ベスト更新の意味、所要時間の推定方法）

### 進化・退化のお知らせ

ホームを開いたとき、計算した段階が `lastSeenStage` と違えば、カードの上に1回だけメッセージを出して `lastSeenStage` を更新する。

- 上がった: 「進化した！ {旧段階名} → {新段階名}」
- 下がった: 「弱くなってしまった… {新段階名}に戻った」
- `lastSeenStage` が未設定（初回）はメッセージなしで保存する

### 開始

初回のホーム表示で `goals` に `creature` を作る（`startWeek` は今週の月曜）。今週すでに記録した分は数える。

## キャラクターの絵（`js/lib/creatureArt.js`）

`monsterSvg(stage, mood): string` — インラインSVGの文字列を返す純粋関数。外部画像は使わない。

- 段階0: 卵（ひび割れ）。段階1〜5: 丸いモンスター。段階が上がるほど体が大きく、腕が太くなり、段階3でハチマキ、段階4でスパイクの頭とダンベル、段階5で王冠・マント・オーラ・頭上のバーベルが付く
- `genki`: ライム色（アクセント色）、笑顔、ほっぺ、キラキラ。`normal`: やや落ち着いた色、口は一文字
- `shobori`: 色が褪せて灰緑になり、少しつぶれ、目が垂れ、汗をかく。段階4のダンベルと段階5のバーベルは床に落ち、王冠は傾く
- 背景が暗い前提（ライム色が映える）。横長のSVG（`viewBox="0 0 140 150"`）

## ファイル構成

| ファイル | 責務 |
|---|---|
| `js/lib/creature.js`（新規） | 定数、週の計算、所要時間、自己ベスト更新、強さ・段階・気分の計算（すべて純粋関数） |
| `js/lib/creatureArt.js`（新規） | `monsterSvg` |
| `js/views/creature.js`（新規） | カードの描画、お休みの切替、`goals` の読み書き、お知らせ |
| `js/views/home.js` | 最上部にカードの置き場を作り、描画を呼ぶ |
| `css/style.css` | カードの体裁 |
| `sw.js` | 新規3ファイルを `ASSETS` に追加、キャッシュを次の版へ |

純粋関数のインターフェース（テスト対象）:

- `weekStart(dateStr): string` — その日を含む週の月曜
- `addDays(dateStr, n): string`
- `sessionMinutes(sets, workouts): number` — 1日分のセットとその日の `workout` 群から所要時間を返す
- `progressExerciseIds(sets, exercises, weekStartStr): string[]` — `sets` は日付つき（`date` を持つ）で受け取る
- `stageFor(power): number`
- `computeCreature({ workouts, sets, exercises, startWeek, restWeeks, today }): Creature`
  - `Creature = { power, stage, mood, weeks: Week[], current: Week }`
  - `Week = { weekStart, rest, closed, sessions: [{ date, minutes, qualifies }], qualified, events: string[], delta }`

## テスト

新規 `test/creature.test.js`（純粋関数のみ）:

- `weekStart`: 月曜はそのまま、日曜は前の月曜、月またぎ・年またぎ
- `addDays`: 月またぎ
- `sessionMinutes`: 手入力の所要時間が優先／自動は差＋5分／1件だけなら5分／同じ日に複数の `workout`
- `progressExerciseIds`: 初めて記録した種目は対象外／推定1RMの更新／同重量での回数更新／軽い重量の回数は比較対象外／自重種目の体重差の許容／補助回数を引いた回数で比較
- `computeCreature`: 毎週満点で強さが増える／0回の週で減る／1回の週で減る／加点は q ≥ 1 のときだけ・上限3／お休み週は増減なし／0と100で丸める／段階の境界／気分の3通り／今週（未終了）は強さを動かさない／開始週より前の記録を数えない／達成した日が3回でも増加は同じ／セットのない `workout` は無視

ブラウザでの手動確認:

- ホームの最上部にカードが出て、強さ・段階・今週の ●○ が計算結果と一致する
- 30分未満の日と以上の日の判定が詳細に出る
- お休みにする → 強さが戻り、戻す → 元に戻る
- 段階が変わったときに1回だけお知らせが出る
- 375px幅で横スクロールがない。ライト／ダークどちらでも読める

## スコープ外

- キャラの名前の付け替え、複数のキャラ、着せ替え
- プッシュ通知・リマインダー
- メンバー間でのキャラの共有（共有機能は休眠中）
- 累計経験値・称号・実績
- 種目別・部位別の成長
- 開始週より前（ジム時代）の記録を育成の増減に使うこと
